# Alpine.js frontend

Run `npm install` and `npm run dev` from this directory. Vite forwards `/api` requests to the Flask server on port 5000. See the [project README](../README.md) for backend setup.

The HTML and Alpine directives live in `index.html`. The Alpine component in `src/main.js` handles dashboard tabs, account navigation, and session requests.

Run `npm run build` for a production bundle or `npm run lint` to check the JavaScript.
